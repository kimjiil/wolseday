# 월세날까지

서울에서 월세날까지 30일을 버티는 도트 생존 웹게임입니다. https://wolseday.com

취준생 윤서, 한부모 정민, 폐업한 사장님 상철 중 한 명을 골라 한 달을 삽니다. 돈만이 아니라 시간, 몸, 사람 사이의 관계까지 함께 바닥나는 구조를 게임으로 옮겼습니다.

## 무림초출 (`#murim`)

같은 페이지에 들어 있는 두 번째 게임. 첫 화면에서 게임을 고르고, 주소 끝의 `#wolse`, `#murim`으로 바로 들어갈 수 있다.

'80억 분의 1' 방식의 무협판에 '활협전'식 육성과 결투를 섞었다. 시대(태평성대·정사대전기·마교 천하)와 태어날 곳을 정하는 기준(출생 수·인구)을 고르면, 지역 12곳 × 집안 14가지 중 하나로 확률에 따라 태어난다(예: '39명 중 1명'). 삶은 실시간으로 흘러가고(속도·멈춤·맡기기), 플레이어는 올해의 중심(수련·생업·가족·양생)과 갈림길의 선택만 정한다. 5·15·30·50·70세에 질문이 나오고, 끝에는 마지막 말과 같은 순간 태어난 네 사람의 삶, 인생의 기록이 남는다.

- **도트 장면**: 384×216 캔버스에 절차적으로 그린다(이미지 파일 없음). 좌표는 192×108 기준이고, 인물은 1배로 그린 뒤 모서리를 다듬어 2배로 키우고 눈·머리카락 광택·옷 주름 같은 세부를 반 칸 단위로 덧그린다(28×48). 배경도 같은 방식으로 2배로 올린다. 배경 37종, 사계절·낮밤·날씨, 인물·동물 스프라이트, 말풍선, 이펙트. 인물은 머리가 몸 절반인 2등신(큰 눈, 외곽선, 머리카락 광택)으로 그리고 머리 모양·옷·무기·표정을 조합해 만든다. 옆모습 말고도 맵에서 쓸 앞모습·뒷모습이 있다. 갈림길·에피소드·수련기 장면마다 따로 무대를 짜고, 아무 일 없는 해에는 나이·집안·올해의 중심에 맞는 일상이 나온다.
- **결투**: 강공 › 변초 › 수비 › 강공으로 물리는 초식에 기 60을 쓰는 절초. 매 합 상대의 낌새가 보이고, 오성이 높을수록 잘 맞는다. 기력은 지금 건강에서 나온다. 비무는 다치기만 하지만 생사결에서 지면 상대가 봐주지 않는 한 죽는다. 이기면 살려 줄지 벨지 고르고, 살려 준 자와 벤 자의 식구는 몇 해 뒤에 다시 찾아온다.
- **장비**: 무기(검·도·수투·암기)·갑옷·장신구를 범품·양품·명품·신병 네 등급으로 얻는다. 전리품, 장터, 우승 상, 사부의 유품, 옛 무덤. 무기는 익힌 무공과 갈래가 맞아야 제 힘을 낸다.
- **기연**: 절벽 아래 동굴, 영약, 은거기인, 별똥 쇳덩이(천외운철)와 신병, 옛 무덤, 죽어 가는 노승, 한담, 취한 거지. 기연 능력치가 높을수록 자주 온다.
- **남들의 싸움**: 사형과 맞수의 진검 승부, 벗의 죽음과 복수, 제자들의 후계 다툼처럼 주인공이 아닌 사람끼리 싸우고 죽는 사건이 있다.
- **수련기**: 무공을 20세 전에 배우면 삼 년을 두 달 단위로 직접 보낸다. 할 일(초식·운기·잡일·기예·휴식·몰래 하산)을 고르고, 동문 셋과 호감을 쌓고, 마지막 비무 시험을 결투로 치른다. 세 장면짜리 에피소드 9개(산문 밖의 아이, 사라진 비급, 다친 새끼 범, 사부의 밤, 주방 할멈, 집에서 온 편지, 맞수의 밤, 습격의 밤, 녹슨 검) 중 2~3개가 사이사이에 끼어든다. 삶에서는 4개(떠돌이 검객, 마른 우물, 전당포의 옥패, 집 나간 동생)가 몇 해에 걸쳐 이어진다.
- **성격과 주사위**: 선택에 따라 성격(의협/셈, 대담/신중, 다정/냉정)이 쌓이고, 성격에 맞는 선택은 d20 판정에 보너스를 받는다.

진행 중인 판과 지난 생 기록은 브라우저 localStorage(`murim_run`, `murim_past`)에만 저장된다. 소리는 기본으로 꺼져 있다(`murim_snd`).

코드는 `index.html` 안에서 `/* ==== murim:이름 ==== */` 주석으로 구역이 나뉜다: core(기본값·상태) → gfx-base·props·chars·stage(도트 엔진) → items → duel → life → events → train·episodes → stage·ui → boot.

## 배포

빌드 과정이 없는 정적 사이트입니다. Cloudflare Pages에 이 저장소를 연결하고 빌드 설정은 비워둡니다.

- 프레임워크 프리셋: 없음
- 빌드 명령: 없음
- 빌드 출력 디렉터리: `/`

`main` 브랜치에 push하면 자동으로 배포됩니다.

## 실시간 접속자 수 (`live/`)

`live/`는 접속자 수를 세는 Cloudflare Worker입니다. Durable Object 하나가 모든 접속을 WebSocket으로 받아 `{"online": N}`만 돌려줍니다.

- 주소: `wss://live.wolseday.com/ws`
- 허용 출처: wolseday.com, www.wolseday.com, *.wolseday.pages.dev, localhost
- 배포: Cloudflare Workers Builds가 `live/` 폴더를 `npx wrangler deploy`로 배포합니다.
- 비용: 무료 플랜 안에서 동작합니다. 대기 중인 접속은 하이버네이션으로 비용이 거의 들지 않고, 30초 ping은 자동 응답으로 처리합니다.

## 오늘의 판 순위표 (`live/`의 `Board`)

같은 Worker에 순위표용 Durable Object(`Board`, SQLite)가 함께 있습니다. 하루(한국 시간)마다 순위표가 새로 열립니다. 인물은 무작위로 뽑고 몇 번이든 다시 뽑을 수 있습니다.

- `POST /api/start` `{seed, char}` → `{id}`: 판 번호 발급. IP당 한 시간에 30번까지.
- `POST /api/score` `{id, name, days, char, end, rents, who, look}` → 순위와 상위 10명. 번호마다 한 번만 올릴 수 있고, 하루를 1.5초보다 빨리 넘긴 기록은 받지 않습니다.
- `GET /api/board?seed=YYYY-MM-DD&char=grad|mom|boss&limit=1~100` → `{total, top, at}` (버틴 날 → 낸 월세 → 먼저 올린 순)
- 이름은 10자까지, 욕설이 들어가면 "익명의 세입자"로 바뀝니다.
- 브라우저에서는 오늘의 판을 처음 한 번만 순위에 올리고, 다시 하는 판은 연습 판으로 처리합니다.

## 판 기록 (`/api/log`, `stats.html`)

판이 끝나면 게임이 익명 기록을 `POST /api/log`로 보낸다. 이름·닉네임·기기 정보는 없고, 인물 유형·나이·성격, 날짜별 잔고·체력·멘탈, 고른 선택지, 자유 시간 행동, 끝난 이유가 들어간다. 한 IP에서 한 시간에 60판까지 받고, 180일 지나면 지운다.

`GET /api/stats?since=30&mode=daily|practice`가 집계를 돌려주고, `wolseday.com/stats.html`에서 볼 수 있다 (검색엔진 노출 안 함).

## 로컬에서 실행

`index.html`을 브라우저로 열면 게임이 됩니다. 접속자 수까지 시험하려면:

```
cd live && npm install && npx wrangler dev
python3 -m http.server 8790   # 저장소 루트에서
# http://localhost:8790/?live=ws://127.0.0.1:8787/ws 로 접속
```
