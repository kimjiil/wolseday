# 무림초출 소스

`index.html` 에 들어가는 무림초출 부분의 원본이다. 고친 뒤 `python3 murim/build.py` 를 돌리면 `index.html` 에 합쳐진다(사이트는 `index.html` 만 읽는다).

## 폴더

| 폴더 | 내용 | 바꾸면 달라지는 것 |
|---|---|---|
| `design/` | 도트 그림을 그리는 코드와 `murim.css` | 겉모습만. 규칙은 그대로 |
| `game/` | 규칙, 사건, 맵 배치, 화면 구성 | 게임이 돌아가는 방식 |
| `page.html` | 무림초출 화면의 HTML 뼈대 | 화면 틀 |
| `skin/` | 이미지 파일로 그림을 갈아끼울 자리 | 아직 비어 있다(연결 전) |

## design/ 안의 파일

- `murim.css` 색·글꼴·배치. 맨 위 `--m-*` 변수만 바꿔도 전체 색이 바뀐다.
- `10_base.js` 붓(P), 색 섞기, 옆에서 본 장면의 땅·하늘
- `20_props.js` 옆에서 본 장면의 소품(집, 나무, 깃발 …)
- `30_chars.js` 인물 차림새 정의, 손에 든 물건, 동물, 초상
- `40_chib.js` 인물 몸 그리기(28×48)
- `50_map.js` 위에서 본 맵의 타일·건물·나무·산
- `60_icons.js` 물건 아이콘

game/ 은 design/ 의 함수를 이름으로 부르기만 한다(예: `charSprite(차림새, 자세, 프레임, 방향)`, `objSprite(물체, 철, 프레임)`, `drawGround(맵, 철)`, `iconUrl(종류, 등급)`). 이 함수들이 같은 크기의 그림을 돌려주기만 하면 안쪽을 어떻게 그리든 게임은 그대로 돈다.

## 천하 지도 자료

`game/23_cathay.js` 에 지역(CREG), 장소(CSITE), 길(CROAD), 강(CRIVER), 호수, 산이 표로 들어 있다. 장소를 옮기거나 더하려면 이 표만 고치면 된다. 천하 지도 화면은 배경 한 장(1536×1152) 위에 장소 단추와 이름표를 올리는 구조라, 배경을 그림 한 장으로 바꾸기 쉽다.

## 출신·지역·문파 자료

`game/10_core.js` 에 지역(REGIONS), 출신(FAM), 문파 안에서 태어나는 출신(SECTBORN), 문파(SECTS)가 표로 들어 있다. 출신 한 줄에 비중(`w`), 재산 범위(`pct`), 태어나는 지역(`region`/`regions`), 천하 지도에서 고향이 붙는 장소(`site`), 집 크기(`tier`), 일터(`ws`)와 일 이름(`wn`)을 적는다.

## 등급 사건 (C · B · A · S · SS · SSR)

`game/62_grade.js` 가 등급 틀이고, 사건은 `game/63_minor_*.js` 에 한 줄에 하나씩 적는다. 지금 1000개(C 450 · B 300 · A 150 · S 70 · SS 25 · SSR 5)가 열 묶음에 나뉘어 있다: 1 어린 시절·마을·무림, 2 출신·살림·가족, 3 강호행·문파·고향, 4 사계절·짐승, 5 일과 돈·관아, 6 낭인·객잔·표국·흑도, 7 문파별·세가·마교, 8 사랑·혼인·벗·원한, 9 기이한 일·절·노년, 10 물건·도성·먼 길.

```js
Q('B','v_boar',{a:[15,60],sea:[2,3]},'field','멧돼지가 밭을 헤집는다.',[
  ['마을 장정들과 몰이를 한다',{p:[.55,'body',.04],ok:['잡았다.',{g:[6,12],fame:.5}],no:['다쳤다.',{hp:-8}]}],
  ['울타리만 고친다','밭 절반은 건졌다.',{g:-3}]]);
```

- 순서: 등급, 이름표, 조건, 배경, 글, 선택지. 조건과 얻는 것에 쓸 수 있는 낱말은 `62_grade.js` 위쪽 설명에 있다.
- 등급이 나오는 비율은 `GODDS`(C 50 · B 28 · A 14 · S 6 · SS 1.7 · SSR 0.3 %), 되풀이 간격은 `GREP`(C 3해 · B 4해 · A 6해, S 이상은 평생 한 번).
- 한 해에 큰 사건이 없으면 `pickMinor()` 가 절반쯤의 확률로 등급 사건 하나를 뽑는다. 풀숲·강호 탐색·길 위에서도 같은 틀로 뽑는다.
- S 이상은 사건이 열릴 때 화면이 번쩍이고 글씨가 뜬다(`evIntro`). 모양은 `design/murim.css` 의 `.mh-gr`, `.mh-call.gss`, `.mh-call.gssr`.
- 새 묶음 파일을 만들면 `build.py` 의 GAME 목록에 이름을 넣는다.

## 물건 (C · B · A · S · SS · SSR)

`game/30_items.js` 가 틀이고(예전 물건 35가지 포함), 나머지는 `game/31_items_w1.js`(검·도), `32_items_w2.js`(권·암기), `33_items_arm.js`(갑옷·머리), `34_items_acc.js`(신발·장신구), `35_items_use.js`(소모품)에 한 줄로 적는다.

```js
IT('w','검','S','칠성검:14:c3r2|태아검:15:c4');      // 이름:공격:덧붙는 힘
IT('a','','A','경번갑:5|은사 조끼:4:e3');             // 이름:방어:덧붙는 힘
IT('c','','A','백옥 패:0:@dice|홍옥 반지:0:c3');      // 장신구는 주된 힘이 없다
IU('A','인삼:hp30ng1|고수의 수련 일지:ex30');         // 이름:쓰면 얻는 것
```

- 덧붙는 힘 글자: `c` 회심% · `e` 회피% · `r` 읽기% · `q` 기 · `h` 기력 · `x` 수련% · `B W L M` 근골·오성·기연·매력 · `@dice @guard @calm @plague @poison` 장신구의 특수한 힘(글자 힘보다 뒤에 적는다)
- **이름이 곧 이름표다.** 저장된 판이 이름으로 물건을 찾으니, 한 번 낸 이름은 바꾸지 않는다. 같은 이름은 등록되지 않고 `ITDUP` 에 쌓인다
- 값은 등급에서 저절로 정해진다(`GV`, `GVU`). 가게 값은 그 1.25배, 되파는 값은 절반
- 물건을 뽑는 곳: `rndItem(자리, 등급, 갈래)`, `dropItem(등급)`, `wOf(옛 등급)`, `shopList(가게)`. 사건의 `wt`·`ar`·`eq` 도 이걸 쓴다
- 아이콘은 자리와 등급으로 정해진다(`design/60_icons.js` 의 `TIERCOL`, `hat`·`boot`·`ring`·`gourd`). 등급 색은 `design/murim.css` 의 `.gr0`~`.gr5`
